# 模板与版式

读取最新文件的封面、正文、技术页、图表页与结束页，提取画幅、主色、字号层级、边距、导航、页脚和页码。不能只看封面就声称掌握整套模板。参考项目用于借鉴结构，不能将其成果、人员和数据复制为当前事实。

| 内容关系 | 候选图式 |
|---|---|
| 层级与支撑 | 分层架构、嵌套分区 |
| 模块集成 | 中心模块与接口分区 |
| 节点详解 | 并列卡片、局部链路 |
| 策略比较 | 对照表、矩阵、共享坐标图 |
| 评估过程 | 性能曲线、指标与诊断关系 |
| 实施计划 | 阶段里程碑、工作包 |
| 项目价值 | 对象—问题—收益映射 |

箭头只表示有向关系；并列和包含用对齐、边框、色块。要求减少箭头时改变图式，不能只换箭头颜色。留白过多时补足证据和机制，不能用更多装饰填空。

场景图可搜索或生图，精确标签和架构优先用可编辑矢量。AI 图片不充当真实现场或系统截图；网络素材保留来源及适用许可，不去水印。用户指定其他成员画图时先规划位置，除非后来授权代做。

局部改前记录目标页及全局影响，改后对比未改页。支持原生保留时优先使用，不无故重建全稿。

导航使用固定标签、顺序和位置，仅高亮所属章节。局部标题可以细分，不能让章节导航跳动。拆页合页后检查全稿页码和导航。

保留原生文字、形状、表格和图表；不为了方便把全部内容截图。字体、颜色和图形数量不设全项目通用硬指标，以用户模板和可读性为依据。
