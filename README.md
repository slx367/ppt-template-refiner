# PPT Template Refiner

从连续改稿经验整理的中文 Agent Skill：复用已有模板、调整内容密度、讲清技术机制、维护章节导航，交付可编辑 PPT。适用于普通汇报、项目介绍、答辩和竞赛。

不会把某项目、20 页、九节点或特定算法固化为通用要求。包含主流程、技术表达、版式策略、质量检查及行为验收案例。

## 使用

将整个 `ppt-template-refiner` 文件夹放入客户端支持的技能目录。技能入口为 [SKILL.md](SKILL.md)。当前交付是可安装包，尚未写入客户端技能目录。

支持显式调用的客户端中输入：

```text
使用 $ppt-template-refiner，以附件 PPT 为模板，保持 16 页。
重点讲清实现与验证，减少套话，保持导航和页脚一致。
不增加未实现功能，交付可编辑 PPTX，检查改动页视觉效果。
```

只改文案也可以：

```text
使用 $ppt-template-refiner，给三个技术模块各写一行标题和两行正文。
标题体现具体能力，不直接写某某优势。先只给文字。
```

此技能是流程和判断规则，不自带生成引擎。实际制作需要环境提供 PPT 编辑与渲染能力；桌面操作、搜索和生图为可选能力。兼容其他 Agent Skills 客户端时须核对其工具和技能发现机制。

发布方法见 [PUBLISH.md](PUBLISH.md)。包内不包含私人对话、原始 PPT、商业模板或其他技能代码。当前未指定开源许可证，公开发布前按自己的授权意愿添加许可证和真实权利人信息；依赖工具与模板各遵守其许可。
